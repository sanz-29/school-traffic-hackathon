
# GateFlow AI

AI-powered school-gate traffic planning and simulation dashboard.

## Project Overview

GateFlow AI helps school administrators compare bell schedules and pickup-zone assignments using configurable constraints, traffic simulation, and transparent performance metrics.

## Current Technology Stack

- Frontend: React, Vite, JavaScript
- Linting: ESLint
- Version Control: Git and GitHub

## Key Objectives

- Compare existing and staggered school schedules.
- Enforce scheduling and pickup-zone constraints.
- Evaluate simulated traffic queues and waiting times.
- Test a 30% increase in vehicle demand.
- Display assumptions, simulation results, and limitations transparently.

## Data and Safety

This hackathon prototype uses fictional or synthetic scenario data. Simulation results are not guarantees of real-world traffic improvement. No children's personal information or live locations should be used.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run lint checks:

```bash
npm run lint
```
